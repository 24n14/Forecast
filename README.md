# 🔮 Forecast Bot

Бот для прогнозирования криптовалют на основе машинного обучения с уведомлениями.

## 🚀 Возможности

- ✅ **ML-прогнозирование** — квантильная регрессия (LightGBM) с прогнозом на 30 дней
- ✅ **Генерация сигналов** — бычьи/медвежьи сигналы с оценкой уверенности
- ✅ **Уведомления** — автоматическая отправка на ntfy.sh
- ✅ **Циклический запуск** — работа по расписанию или однократно
- ✅ **Технический анализ** — 61 паттерн японских свечей (TA-Lib), индикаторы RSI/SMA

## 📦 Установка

```bash
# Клонировать репозиторий
git clone git@github.com:24n14/Forecast.git
cd Forecast

# Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Установить зависимости
pip install -r requirements.txt
```

## ⚙️ Настройка

Отредактируйте `config.py`:

```python
# Торговые настройки
SYMBOL = "BTCUSDT"
TIMEFRAME = "D"
HISTORY_DAYS = 180

# Уведомления
NTFY_TOPIC = "forecaster_24n14"
ENABLE_NOTIFICATIONS = True

# Параметры сигналов
SIGNAL_THRESHOLD_STRONG = 10.0  # Порог для сильного сигнала (%)
SIGNAL_THRESHOLD_WEAK = 5.0     # Порог для слабого сигнала (%)

# Планировщик
SCHEDULE_ENABLED = False        # True для работы по расписанию
SCHEDULE_TIME = "09:00"         # Время запуска (UTC)
```

## 🏃 Запуск

### Однократный запуск

```bash
python main.py
```

### Циклический запуск по расписанию

```bash
# Из config.py (SCHEDULE_ENABLED=True, SCHEDULE_TIME="09:00")
python main.py

# Или через аргументы командной строки
python main.py --scheduled --schedule-time "09:00"
```

### Старый метод (без планировщика)

```bash
python start.py
```

## 📊 Как работает прогноз

1. **Загрузка данных** — скачиваются свечи с Bybit (BTCUSDT, дневной таймфрейм)
2. **Расчёт признаков** — 19 признаков: динамика цены, объём, RSI, SMA, паттерны свечей
3. **Прогноз** — квантильная регрессия на 3 квантилях (5%, 50%, 95%)
4. **Генерация сигнала**:
   - `STRONG_BULLISH` / `STRONG_BEARISH` — медиана > 10% (или < -10%)
   - `WEAK_BULLISH` / `WEAK_BEARISH` — медиана > 5% (или < -5%)
   - `NEUTRAL` — медиана в диапазоне [-5%, +5%]
   - Уверенность `HIGH` — все квантили смотрят в одну сторону
5. **Уведомление** — отправка на ntfy.sh с приоритетом по силе сигнала

## 📱 Получение уведомлений

1. Установите приложение [ntfy](https://ntfy.sh/) на телефон
2. Подпишитесь на топик `forecaster_24n14` (или измените в `config.py`)
3. Получайте push-уведомления с прогнозами

Веб-версия: https://ntfy.sh/forecaster_24n14

## 🛠 Обучение модели

Модель уже обучена (`models/sliding_quantile_model.pkl`). Для переобучения:

```bash
python model_trainer.py
```

**Параметры обучения:**
- Окно: 30 дней
- Прогноз: 30 дней вперёд
- Признаки: 19 (цена, объём, индикаторы, паттерны)
- Walk-forward валидация: 941 шаг

**Результаты (средние):**
- Модель лучше базовой линии в 78% шагов
- Улучшение pinball loss на 32%
- Средняя ошибка медианы: 6.63 п.п.

## 🔧 Технологии

- **Python 3.10+**
- **LightGBM** — градиентный бустинг для квантильной регрессии
- **TA-Lib** — технический анализ (61 паттерн свечей, RSI, SMA)
- **Pandas/NumPy** — обработка данных
- **SQLAlchemy** — работа с базой данных
- **Bybit API (pybit)** — загрузка свечей
- **ntfy.sh** — push-уведомления
- **schedule** — планировщик задач

## ⚠️ Дисклеймер

Это бот **только для прогнозирования и уведомлений**. Он **НЕ торгует** и **НЕ выставляет ордера**.

Прогнозы основаны на исторических данных и не являются финансовым советом. Используйте на свой страх и риск.
